# 小学口算题生成器 · 人教版

打开即用的网页版口算题生成工具，不用安装、不用联网（首次加载后可离线使用）。

**在线使用：** https://tarma945-debug.github.io/kousuan/

---

## 能做什么

- 按 **年级**（1–6）× **上下册** × **题型** 选，题型可多选，定好题量一键生成
- **两套教材版本**可切换：新版 2024（2022 课标，2024 秋起使用）/ 旧版 2012 审定版
- 题目可 **按表格复制**，直接粘到 Excel / WPS 自动分列
- 可 **一键存成图片**：宽度固定 900px、字号固定不动，只含题目本身
- 屏幕用宋体 13 号，分数按教材规范 **上下叠写**（不是 5/9 这种斜杠）

## 题型覆盖

新版 64 个题型 / 旧版 59 个题型，覆盖人教版小学阶段主要口算考点。

三年级上册「混合运算」按教材三个小节拆分，完整覆盖 20 种结构：

| 题型 | 结构 |
| --- | --- |
| 混合运算（同级） | `A+B−C` `A−B+C` `A×B÷C` `A÷B×C` |
| 混合运算（不同级） | `A+B×C` `B×C+A` `A−B×C` `B×C−A` `A+B÷C` `B÷C+A` `A−B÷C` `B÷C−A` |
| 混合运算（带小括号） | `(A+B)×C` `C×(A+B)` `(A−B)×C` `C×(A−B)` `(A+B)÷C` `(A−B)÷C` `A+(B×C)` `A−(B+C)` |

数值范围：乘法仅表内乘法或多位数 × 一位数；除法仅表内除法且整除；加减结果不超过 3000；不出负数。

## 技术说明

单个 HTML 文件，零依赖、零构建，双击就能用。所有逻辑（题目生成、排版、图片导出）都在浏览器里跑，没有后端。
